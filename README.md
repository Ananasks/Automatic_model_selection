# Classical Model Autoselector for Ionospheric Time Series

Автоматизированный ML-пайплайн для обучения, сравнения, выбора и дообучения классических моделей регрессии на временных рядах ионосферных параметров.
Это исследовательский ML-проект, который показывает умение строить воспроизводимый pipeline для временных рядов: от подготовки данных и инженерии признаков до честной валидации, выбора модели и сохранения артефактов эксперимента.

Ключевой акцент сделан на корректной логике для time-series задач:

- test-часть берётся из более позднего участка ряда, без случайного перемешивания;
- scaler обучается только на train-части, чтобы не было data leakage;
- каждая целевая переменная обучается и дообучается в своей директории артефактов;
- результаты сохраняются в виде моделей `.pkl` и Excel-отчётов для последующего анализа.

## Что делает проект

- Загружает временные ряды из CSV в двух форматах: с колонкой `datetime` или с парой колонок `date` + `time`.
- Создаёт календарные признаки: час, день недели, месяц, день года, неделя года и другие.
- Применяет HP-фильтр к целевой переменной для сглаживания временного ряда.
- Делит временной ряд хронологически: первые 80% выбранного интервала идут в train, последние 20% — в test.
- Обучает несколько моделей регрессии:
  - `LinearRegression`
  - `Lasso`
  - `MLPRegressor`
- Сравнивает модели по метрикам `R²`, `MAE`, `MAPE`.
- Автоматически выбирает лучшую модель по `R²`.
- Сохраняет обученные модели, scaler, список признаков и Excel-отчёты.
- Загружает лучшую модель для той же целевой переменной и дообучает её на новых временных участках.

## Логика пайплайна

1. CSV-файл приводится к единому datetime-индексу.
2. Для каждого наблюдения создаются календарные признаки.
3. Целевая переменная сглаживается HP-фильтром.
4. Выбранный диапазон дней делится хронологически на train/test.
5. `StandardScaler` обучается только на train-части.
6. Обучаются `LinearRegression`, `Lasso`, `MLPRegressor`.
7. Лучшая модель выбирается по `R²`.
8. Модель, scaler, список признаков и отчёты сохраняются в `trained_models/`.
9. На новых интервалах загружается лучшая модель для той же целевой переменной и выполняется дообучение.

## Быстрый старт

Создайте окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Положите входные CSV-файлы в корень проекта или измените пути в функции `main()`:

```python
abs_file = "absTEC_absCB_dayStart_1_daysCount_309_year_2022_startStation_tetu_filted_CB.csv"
muf_file = "total_muf_30_minuts.csv"
```

Запустите пайплайн:

```bash
python3 model_autoselector.py
```

После запуска результаты сохраняются в директорию `trained_models/`.

## Ожидаемый формат данных

Скрипт поддерживает два варианта CSV.

Вариант 1:

```text
datetime,target_column,feature_1,feature_2,...
```

Вариант 2:

```text
date,time,target_column,feature_1,feature_2,...
```

Целевая колонка задаётся через `ExperimentConfig`:

```python
config = ExperimentConfig(
    file_path="data.csv",
    target_column="muf",
    day_start=50,
    day_stop=100,
    dataset_name="MUF",
)

trainer = ModelTrainer(config)
trainer.run()
```

## Основные классы

`ExperimentConfig` хранит настройки одного эксперимента:

- путь к CSV;
- целевую колонку;
- диапазон дней;
- имя папки для артефактов.

`ModelTrainer` отвечает за первичное обучение:

- загрузка и обработка данных;
- генерация временных признаков;
- хронологическое разделение на train/test;
- нормализация признаков без утечки test-данных;
- обучение набора моделей;
- выбор лучшей модели;
- сохранение моделей и отчётов.

`ModelFineTuner` отвечает за повторное использование лучшей модели:

- загрузка scaler, признаков и лучшей модели;
- подготовка нового участка данных;
- выравнивание признаков под сохранённую модель;
- дообучение модели на той же целевой переменной;
- расчёт метрик;
- сохранение дообученной версии.

## Что демонстрирует код

- Умение работать с реальными CSV-данными, где формат времени может отличаться.
- Понимание типичных ошибок ML-пайплайнов, включая data leakage.
- Базовую архитектуру экспериментов: конфигурация, обучение, оценка, сохранение артефактов.
- Практическое сравнение нескольких моделей на одной задаче.
- Дообучение модели на новых временных интервалах.

## Почему это полезно

Проект демонстрирует практический ML-пайплайн для исследовательских временных рядов: подготовку признаков, воспроизводимое обучение, честную проверку на более позднем участке ряда, сравнение моделей, сохранение артефактов и дообучение на новых интервалах данных. Такой формат подходит для задач прогнозирования физических параметров, где важно быстро сравнивать несколько базовых моделей и фиксировать результаты экспериментов.
